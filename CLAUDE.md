# EC Itapetininga

A aplicação está em `mobile/` (Expo, React e React Native); a API e a configuração do MySQL estão em `backend/`. Consulte os READMEs dessas pastas e `mobile/AGENTS.md` antes de modificar o projeto.

O conteúdo visual histórico em `mobile/reference/` serve como referência para o gerador e para testes visuais. Preserve acessibilidade, navegação por teclado, identidade azul e amarela e tipografia do clube. Nunca adicione credenciais reais ao repositório.
